# Editorial product fixture

Active Structure Lock v1 for a Vietnamese long-form knowledge publication (bilingual vi/en): home (featured essay, latest essays list, topics), essay page (title, standfirst, author, body with images/footnotes, related essays), topic archive.

Content: essays 2,000–6,000 words, editorial photography with captions. Current draft UI wraps every essay excerpt, pull quote, and paragraph group in shadowed cards with 14px body text at full container width.
