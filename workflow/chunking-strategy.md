# Chunking strategy

Use chunking for 30+ pages, multiple roles, migrations, or complex flows. Establish shared context once—active registry, terminology, global IA/design system, open issues, and lock—then work in role, domain, flow, or page batches.

```text
Global context → shared system → batch 1 → review/summary → batch 2 → review/summary → cross-batch review
```

Each handoff contains active artifacts/versions, concise batch summary, resolved decisions, open issues, dependencies, and next batch scope. A later batch reads that handoff and active shared artifacts, not every prior batch’s raw material. Run terminology and cross-flow/page consistency after relevant batches.
