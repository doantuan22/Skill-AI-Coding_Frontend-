# Visual review

Use `VISUAL-REVIEW.md` to inspect rendered output against Design Direction, Design System, Page Spec, and Structure Lock. Check alignment, spacing, hierarchy, typography, contrast, overflow, layout shift, image crop, button/form/component consistency, responsive behavior, and state presentation.

Classify findings as `BLOCKER`, `MAJOR`, `MINOR`, or `POLISH`. A hidden mobile CTA or broken tablet form is at least major/blocker according to impact. A semantic lock mismatch is a blocker and returns to Phase 1; non-structural findings return to Phase 2.
