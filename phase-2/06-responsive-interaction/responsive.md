# Responsive engine

Realize the responsive intent in locked Page Specs without changing semantic responsibilities. Define desktop, laptop, tablet, and mobile adaptations using the existing breakpoint system or content-driven breakpoints. Prefer fluid layouts, grid/flex, min/max/clamp, minmax, auto-fit/auto-fill, aspect-ratio, logical properties, and container queries only where they simplify the solution.

Adapt information, not merely dimensions: a table may become a card/list, a sidebar a drawer, a two-column form a single column, and a toolbar collapsible controls. Keep critical context, primary actions, recovery paths, and required data accessible at every target viewport.
