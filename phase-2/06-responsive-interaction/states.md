# State realization

Implement the locked `STATE-MAP.md` rather than rendering blank regions. Cover applicable loading, empty, no-match, error, success, disabled, permission-denied, partial-data, and cancellation states. Each state must preserve a meaningful next action or recovery path when one exists.

Tables require header, row, hover/selection when relevant, empty, loading, pagination, actions, and responsive transformation. Images require aspect ratio, object-fit, placeholder/fallback, and lazy-loading behavior where appropriate to reduce layout shift.
