# Design system rules

Typography levels must state family, size, weight, line-height, and letter spacing; prefer a small readable set of families and weights. Define grid/container/breakpoint intent in terms of the existing system and content needs. Iconography uses one compatible system; reuse an existing icon library and do not use emoji as product icons unless requested.

Imagery specifies aspect ratio, object fit, placeholders, fallback, and lazy-loading intent. Motion uses named durations and communicates change, hierarchy, or feedback rather than decoration.
