# Token strategy

Tokens cover semantic color, spacing, radius, border, shadow/elevation, typography, breakpoint, motion, and z-index. Map them to the existing stack: CSS custom properties, Tailwind theme, Bootstrap variables, SCSS, theme object, or another established mechanism. Do not change the stack merely to introduce tokens.

Use semantic names such as `color-primary`, `surface-elevated`, `text-muted`, and `border-strong`, including hover/focus/active/disabled/selected/error/success states. Use a deliberate spacing scale rather than arbitrary repeated values. Token exceptions must state why they are intentional.
