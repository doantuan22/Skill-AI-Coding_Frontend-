# Consistency and drift audit

Inspect pages for random colors, spacing, radius, shadows, duplicate button/form/card patterns, inconsistent icon/header sizes, and cross-page differences in navigation, CTA hierarchy, tables, modals, empty/error states, and responsive patterns.

Compare exceptions against the Design System. Classify each as an intentional documented exception or design drift; normalize drift. Verify Page Specs: required sections/actions/states and navigation remain present. Compare implemented UI to Structure Lock; a semantic mismatch is a blocker, never a polish issue.
