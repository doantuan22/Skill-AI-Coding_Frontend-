# AI tell density

Generic output is assessed as a cluster, not by a permanent blacklist. A tell is a review signal only when it is unexplained by product, audience, brand or task.

| Result | Interpretation | Action |
|---|---|---|
| 0–1 unexplained, isolated signals | no material density | record exception if notable; preserve otherwise |
| 2–3 reinforcing signals in one region | possible template drift | inspect hierarchy, character and component grammar |
| 4+ reinforcing signals or repeated across page | high generic-density risk | run adversarial review; remove/replace at the root then recapture |

Signals may include uniform pills, gradient CTAs, decorative glows, card nesting, decorative icons, rainbow semantics, generic hero anatomy, trend-only type, ornamental motion, or non-specific copy. The list evolves; the decision question does not: *what task- and direction-specific reason justifies this combination?*
