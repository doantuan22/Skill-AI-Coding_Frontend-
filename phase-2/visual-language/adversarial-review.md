# Adversarial visual review

Review from four perspectives, seeking evidence rather than taste assertions.

1. **Senior product designer:** Does the visual hierarchy help the actual task and audience?
2. **Design-system owner:** Are tokens, grammar and repeated components converging instead of drifting?
3. **Frontend craft reviewer:** Are boundaries, radii, interaction states, overflow, loading and responsive behavior physically coherent?
4. **Anti-generic reviewer:** Could the page be mistaken for a category template because several unexamined defaults cluster together?

For each finding: name the signal, its product impact, active grammar rule, smallest viable correction, and whether the existing system should be preserved. Do not demand a rewrite based on a single stylistic tell.
