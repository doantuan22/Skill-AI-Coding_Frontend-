# Motion character

State the intended feel (quiet, direct, tactile, spatial) and map it to only necessary transitions: feedback, state change, orientation and progressive disclosure. Define duration/easing family, interruption behavior and `prefers-reduced-motion` equivalent. A static solution is valid when motion adds no information.

Character options, intensity budget, timing ranges, vocabulary and reduced-motion equivalents are defined by the [Motion Engine](../motion/README.md). Record the chosen character here for low-budget work, or link `MOTION-SYSTEM.md` when it exists; do not maintain two definitions.
