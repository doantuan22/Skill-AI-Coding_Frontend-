# Evidence contract

Evidence records screenshot or capture reference, route, viewport ID, timestamp/session, Phase, iteration, render status, basic DOM/root result, optional console observation, and execution errors. Use stable names such as `PAGE-LOGIN__mobile__iter-01.png`, never `final2.png`.

An execution issue record includes ID, page, route, viewport, type, severity, evidence reference, description, expected, and actual. Retain latest valid evidence and evidence tied to unresolved blockers; no storage platform is required.
