# Accessibility failures

Codes: `AXE_NOT_AVAILABLE`, `AXE_RUNTIME_FAILURE`, `AXE_INJECTION_FAILURE`, `ACCESSIBILITY_SCAN_FAILURE`, `AUTH_REQUIRED`, `ACCESSIBILITY_EVIDENCE_CORRUPTION`, `CRITICAL_A11Y_UNRESOLVED`, `SERIOUS_A11Y_UNRESOLVED`, `ACCESSIBILITY_GATE_BYPASS`, `STALE_A11Y_EVIDENCE`, `A11Y_FIX_LOOP`. Desktop/mobile partial scans preserve valid evidence and report `PARTIAL`.
