# Component structure

Create `COMPONENT-MAP.md` after page responsibilities are clear. Define reusable components by functional responsibility, inputs, outputs, states, constraints, and the pages/sections that use them. Identify repeated structures and propose one shared structural component where its behavior is genuinely the same.

Component maps may specify a search bar, filter panel, data table, form section, page header, or confirmation dialog. They must not specify visual styling, exact typography, colors, shadows, or CSS.
