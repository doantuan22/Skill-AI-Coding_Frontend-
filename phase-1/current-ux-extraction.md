# Existing UX extraction

Use this module only when an interface or implementation already exists. Create `CURRENT-UX-MAP.md` as an observational inventory of routes, pages, templates, components, forms, navigation, roles, authentication boundaries, current flows, backend-facing contracts, and reusable structural patterns.

Record existing hierarchy and interactions without judging visual quality or silently redesigning it. Compare the inventory with the normalized requirement, then route missing or conflicting structure to the appropriate Phase 1 artifact.
