# Structural wireframe engine

Create `WIREFRAME-SPEC.md` after pages, sections, actions, data, and states are known. Wireframes describe hierarchy, grouping, navigation placement, action placement, form grouping, table structure, content order, persistent versus collapsible content, and responsive transformation intent.

Use named sections and IDs so the wireframe links back to page specs and traceability. Do not specify color, font, decoration, visual effects, pixel measurements, or final component appearance. Read [references/wireframe-rules.md](references/wireframe-rules.md) only while creating or reviewing wireframes.
