# Decision prompts

Use these questions before committing a structural decision; they are internal guardrails, not mandatory user-facing output.

| Area | Ask before deciding |
|---|---|
| User | Who uses this, what are they accomplishing, how often, and what knowledge can be assumed? |
| Goal | What is the main goal, shortest reasonable path, and information needed before action? |
| Page | Does it need a dedicated page, inline region, modal, drawer, or step in an existing flow? |
| Action | What is primary, what is secondary, what is destructive, and what follows each action? |
| State | What happens during loading, with no data, on error, and after success? |
| Navigation | Where did the user come from, where can they go next, and how do they return? |

If the answer depends on an unconfirmed business rule, record a question rather than deciding it.
