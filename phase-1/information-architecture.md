# Information architecture and navigation

Build `INFORMATION-ARCHITECTURE.md` and `NAVIGATION-MAP.md` from users, goals, use cases, and confirmed system constraints. Define hierarchy, grouping, labels, taxonomy, discoverability, progressive disclosure, wayfinding, and content priority before page-level structure.

Navigation must distinguish global, role, local, breadcrumb, tabs, contextual actions, and back behavior when they apply. Do not expose backend/database structure directly as UI structure. See [references/information-architecture.md](references/information-architecture.md) when modelling IA and [references/navigation.md](references/navigation.md) when modelling movement.
