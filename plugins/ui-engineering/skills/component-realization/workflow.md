# Component realization workflow

Read the locked `COMPONENT-MAP.md`, Page Specs, State Map, relevant design-system decisions, and selected [Visual Grammar](../visual-language/README.md) decisions. Search existing shared components before creating a new one. Extend/reuse when the functional contract is compatible; create a new component only for a distinct responsibility.

Create `COMPONENT-SPEC.md` or focused component records for important shared components. Map each realized component to its pages and implementation location through `IMPLEMENTATION-MAP.md`.

Component Specs own implementation variants and semantics; they must cite the Visual Grammar behavior they realize rather than silently introducing a new visual language.
