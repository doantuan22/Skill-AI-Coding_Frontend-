# Navigation

Specify what is global, role-specific, local, contextual, and reversible. Each important flow needs an entry context, a next destination, and a way back that does not lose necessary work. Use breadcrumbs for hierarchical location, tabs for peer content within one context, and contextual actions for actions tied to the current object.

Avoid duplicate navigational paths with different meanings, dead ends after failure, and labels that change for the same concept.
