# Structure Lock integration

After Phase 1 review passes, create or update `STRUCTURE-LOCK.md` using its template. The lock must name the exact versions of the active artifacts and freeze actors, use cases, critical flows, pages and responsibilities, required sections, primary actions, required states, business constraints, required data, and navigation relationships.

Phase 2 may refine visual styling, typography, colors, spacing, component appearance, micro-interactions, responsive visual adaptation, and semantic-preserving layout refinement. It may not remove a required page/action/form datum, change business flow, actor permission, API contract, route semantics, or merge flows in a way that changes business behavior. Such a discovery rolls back to Phase 1 and requires a new reviewed lock.
