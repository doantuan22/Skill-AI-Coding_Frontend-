# Manual accessibility review

Review keyboard reachability, focus order/visibility/restoration, skip/navigation, modal/menu behavior when applicable, form error comprehension, content hierarchy, touch target usability, responsive accessibility, reduced motion, and color-only communication. Each item is `PASS`, `FAIL`, `LIMITED`, `NOT_EXECUTED`, or `NOT_APPLICABLE` with page, viewport, evidence, and notes. Do not claim manual pass without an interaction-capable tool/human review.
