# Content patterns

For reading, reference, listing and dense product surfaces.

| Pattern | When | Composition | Typography link | Failure |
|---|---|---|---|---|
| **Long-form article** | Editorial, blog, knowledge | Single reading column (55–75ch) with media breakouts, captions, pull quotes | [body-type](../../typography/body-type.md), [typographic-composition](../../typography/typographic-composition.md) | Full-width paragraphs; cards around paragraphs |
| **Docs layout** | Developer/technical documentation | Left nav, content column, right "on this page"; code blocks with copy | [technical-type](../../typography/technical-type.md) | Marketing hero styling in docs; unscannable headings |
| **Index / archive** | Collections of articles/projects | Typographic list or asymmetric grid with dates/categories | editorial archetype | Equal cards with thumbnails for text-only content |
| **Listing grid/list** | Marketplace/travel results | Consistent media ratio; price/rating hierarchy; filters sidebar or sheet on mobile; list/map toggle when geographic | dense-transactional | Inconsistent card heights; badges everywhere |
| **Detail page** | Product, property, listing | Gallery → key facts → decision panel (sticky on desktop) → details/reviews | compact product title | Decision panel far from key facts |
| **High-density product** | Dashboards, admin, analytics | App shell, tables, panels; alignment and type create hierarchy; minimal cards | dense-transactional + tabular numerals | Marketing-style large type and generous whitespace inside apps |
| **Low-density premium** | Brand/product narrative pages | Few elements per viewport; scale contrast; full-width bands | premium-modern | Low density used to stretch thin content |

Dense and reading layouts follow [references/tables.md](../../references/tables.md) and [dashboard](../../references/dashboard.md) guidance where relevant.
