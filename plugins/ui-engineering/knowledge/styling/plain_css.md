## 1. Modern CSS Variables & Responsive Architecture
- **CSS Custom Properties**: Define theme variables in `:root` (`--color-primary`, `--font-main`, `--radius-md`).
- **Layout Rhythm**: Use Flexbox and CSS Grid layouts with fluid units (`clamp()`, `minmax()`, `rem`).
- **No Class Clashing**: Use BEM or prefix naming (`.c-card`, `.c-card__header`) to prevent selector collisions in global stylesheets.
