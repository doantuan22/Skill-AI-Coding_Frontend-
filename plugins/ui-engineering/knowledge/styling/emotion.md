## 1. CSS Prop & Styled Components
- **`css` Prop**: Use `@emotion/react`'s `css={{ ... }}` prop for concise, theme-aware inline styling.
- **Theme Variables**: Reference `theme` provided by `ThemeProvider`. Avoid hardcoded style strings.
- **Preservation**: Retain established Emotion configuration (Babel/SWC jsxImportSource).
