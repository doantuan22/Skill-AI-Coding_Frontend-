# Craft foundations

- Make the primary task perceptually dominant; secondary content recedes through hierarchy, not extra containers.
- Use spacing, alignment and type contrast to create groups. Repeated equal gaps and equal-weight cards flatten meaning.
- Align nested radii and borders to the same visual boundary. Elevation is neutral, sparse and consistent with the surface profile.
- Specify default, hover, focus-visible, pressed, disabled, loading, success, empty and error states where applicable.
- Verify type measure, contrast, target size, zoom and reduced motion through the accessibility path; craft review never substitutes for accessibility verification.
- Prefer deletion, reuse and normalization over decorative additions.
