# Navigation grammar

Navigation reveals location and available destinations, not generic decoration. Define active, hover, focus, compact/mobile and overflow states. Icons may reinforce familiar destinations but labels/semantics own clarity. Avoid treating every nav item as a pill, badge or highlighted card.

| Component | Rules |
|---|---|
| Sidebar | Labels always visible when expanded; collapsed state keeps accessible names and tooltips; active item by weight/indicator, not a pill on every item |
| Tabs | For parallel views of one subject; indicator motion `motion.m2-tabs`; scrollable on mobile |
| Breadcrumbs, pagination | See [command-search.md](command-search.md) |

Presentation patterns (minimal header, mega menu, section nav) are in [navigation patterns](../../web-patterns/navigation/navigation-patterns.md).
