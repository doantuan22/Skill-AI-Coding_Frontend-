# Icon grammar

Select one coherent family and define outline/filled use, stroke/weight, optical size, color role and spacing. Classify each icon as action, navigation, status, semantic content or decoration. Decorative icons require a documented information/composition job; otherwise remove them.

Use familiar glyphs only for actions users can recognize; icon-only controls need accessible names. Do not mix emojis, multiple visual families, rainbow icon colors or colored-box filler. Distinguish status icons from generic decoration and never communicate state through color alone.
