# Component grammars

Design knowledge and implementation guidance for components. The grammars define visual and behavioral rules; Component Specs define APIs and locations. They are not a UI library.

| Cards and surfaces | [surfaces.md](surfaces.md), [data-display.md](data-display.md) | `effect.shadow`, `layout.grid-card-matrix` |
